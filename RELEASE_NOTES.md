# OSED Forge 0.4 — Mission desk

A focused, playful study experience for an English learner studying technical material.

- A recommended mission and connected learning path, with earned XP and levels.
- Clearer explanations across all 57 lessons, plus a 20-term word guide.
- Guided examples, independent checks, recaps, spaced review, and light/dark modes.
- Exam-prep checklist and lab evidence, explicitly marked as self-reported.
- A four-stage practical mission: predict a bounded copy, observe it in WinDbg, investigate a fresh branch input, then record and repeat the result.
- Practical notes survive navigation and reload. Failed saves keep the draft; guided attempts cannot be labelled independent.
- Form draft recovery, inline validation, accessible backup confirmation, and updated offline cache.
- A self-contained HTML browser edition built from the same source.

Progress retains the v1 journal format. Export your backup before upgrading.
Advanced native exploit labs remain incomplete. This release does not guarantee an exam pass.

Validation details are in docs/REDESIGN_QA.md. Windows build and installation status must be checked on the exact commit's GitHub Actions run.
